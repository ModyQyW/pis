# QA and verification matrix

Run the narrowest check that exercises the change. This file lists the cases
that must be covered before delivery. Record results in `03-progress.md`.

## Commands

```sh
go build ./... && go vet ./...
go test ./...
bun install
bun run typecheck
bun run test
bun run build
```

Real-pi checks are opt-in (they cost model calls); a fake RPC process covers
protocol/UI behavior deterministically.

## Functional matrix

### Shell and lifecycle

- [ ] App launches from Finder with a minimal `PATH`; finds pi through settings,
      PATH, common locations, or login shell.
- [ ] Missing pi: onboarding explains the install command and a path picker.
- [ ] Unsupported pi (too old/new major): clear error, no project mutation.
- [ ] Window remembers size/position; min size respected.
- [ ] Hidden inset title bar: traffic lights, drag regions, no overlap, full
      screen, light/dark.
- [ ] Native menu: Edit copy/paste works; shortcuts route; Quit guard.
- [ ] Single instance; second launch focuses the existing window.
- [ ] Quit with 0/1/N running sessions; children exit; no orphans.
- [ ] App restart restores last workspace/session and drafts.

### Workspaces and trust

- [ ] Add via folder picker; recent list; remove without deleting files.
- [ ] Project with no trust-requiring resources opens without a prompt.
- [ ] Project with `.pi/extensions`, `settings.json`, `skills`, `prompts`,
      `themes`, `mcp.json`, `SYSTEM.md`, or `APPEND_SYSTEM.md` prompts once.
- [ ] Untrusted project: local extension command is absent; user extensions
      still load; no crash.
- [ ] Trusted project: local extension command is present.
- [ ] Trust decision change restarts the session and updates commands.
- [ ] pi `trust.json` true is honored; app never writes it.
- [ ] Path with spaces, unicode, symlink; workspace root is a file → error.

### Sessions

- [ ] New session: empty state, pi starts, first prompt streams, title updates.
- [ ] Resume a large real session: transcript paints fast; tool cards correct;
      compaction shown; model/usage restored.
- [ ] Subagent run directories are not listed as chats.
- [ ] Rename; delete to Trash; reveal; export HTML.
- [ ] Multiple open sessions run concurrently; switching does not abort.
- [ ] Close/sleep a session stops it; resume restarts; history intact.
- [ ] Fork from a user message; clone; tree view; navigate branch (with and
      without summary).
- [ ] Two app processes or a foreign lease: second open refuses/warns.
- [ ] Session with missing model: sending is blocked with a clear picker.

### Chat and streaming

- [ ] Text, thinking, tool calls, tool results, images, errors render.
- [ ] Long stream (100 KB) stays smooth; no O(n²) growth; no dropped deltas.
- [ ] Provider retry/abort; aborted message shows partial state.
- [ ] Tool call with streaming bash output updates in place; full output opens.
- [ ] Edit/write diff; read preview; grep/find/ls; todo; ask-user-question.
- [ ] Unknown extension tool: generic card, JSON args/result, expandable.
- [ ] Tool result images; image lightbox; copy.
- [ ] Compaction start/end; summary divider; token counts; manual compact.
- [ ] Context/cost/tokens update after settle; no polling.
- [ ] Queue while running: steer vs follow-up; clear queue restores text.
- [ ] Stop mid-stream; stop mid-tool; stop while waiting for approval.
- [ ] Scroll-up during streaming does not force-scroll; jump-to-bottom.
- [ ] Selection/copy across rows; links open externally.

### Composer and commands

- [ ] Enter sends; Shift+Enter newline; IME composition does not send.
- [ ] @file fuzzy search; keyboard navigation; large repo cap.
- [ ] Slash commands: extension/prompt/skill; search; execute; errors surface.
- [ ] Image paste/drop; text attachment; remove; size limits; preview.
- [ ] Model picker: groups, search, current model, unavailable models hidden.
- [ ] Thinking levels reflect model capabilities; clamp behavior.
- [ ] Plan toggle reflects actual bridge state; approve exits plan mode.
- [ ] Drafts per session survive switching and restart.

### Extension UI

- [ ] `select`: options, keyboard, free-text answer, cancel.
- [ ] `confirm`: allow/deny, no auto-deny, pending indicator.
- [ ] `input`; `editor` multiline; prefill; cancel.
- [ ] Multiple pending dialogs queue in order; no deadlock.
- [ ] `notify` toast; `setStatus` chip; `setWidget` drawer; `setTitle`.
- [ ] Extension error shows path/event and diagnostics copy.
- [ ] Ask-user-question RPC fallback completes a 1- and 4-question flow.
- [ ] Package install/remove/update output visible; failure does not break app.

### Changes/files

- [ ] Clean, modified, staged, untracked, deleted, renamed files.
- [ ] Unified diff correct; binary/large files handled; copy patch.
- [ ] Open in editor; reveal in Finder; path traversal rejected.
- [ ] File preview: text, Markdown, image; size cap; no HTML execution.
- [ ] Refresh debounce after tool completion/focus; no busy loop.

### Auth/onboarding

- [ ] No models: onboarding explains provider login; model list refreshes.
- [ ] Login sheet runs `pi auth login`; success, cancel, failure, exit.
- [ ] No credentials logged; buffer cleared; terminal resize.
- [ ] Logout updates model list.

### Performance

- [ ] Warm window visible < 700 ms.
- [ ] 1k-message fixture first paint < 150 ms.
- [ ] 10k-line bash result expansion does not freeze.
- [ ] Idle CPU ~0%; no polling timers visible in traces.
- [ ] Idle footprint < 120 MB excluding pi.
- [ ] Bundle < 30 MB excluding pi.
- [ ] Cached session switch < 100 ms.

### Security

- [ ] Untrusted origin cannot call bound methods.
- [ ] Markdown raw HTML/script is removed; `javascript:` links blocked.
- [ ] File methods restrict to workspace/allowed paths; symlink escapes checked.
- [ ] Custom scheme does not serve arbitrary user HTML to a trusted page.
- [ ] Logs/diagnostics contain no prompts, credentials, or env secrets.
- [ ] Project trust off means no project extension execution.
- [ ] Approval requests cannot be satisfied by renderer-only state.

## Visual QA

checks. Capture:

- Empty home, first run, no pi, no models.
- Sidebar with projects/open/recent sessions, running/needs-input/error states.
- Streaming answer with thinking, tool cards, diff, image.
- Changes panel with a multi-file diff.
- Extension dialog dock, approval card, plan mode, todo.
- Light/dark/system; narrow window; full screen.

Check: no clipped text, no layout jump when streaming, focus rings, contrast,
keyboard-only flow, reduced motion.
