PiS 0.0.4 is the public release of the changes prepared in the 0.0.3 draft.

- Vite+ formatting, lint, and type checks now run in one gate.
- The Rspress user guide is separate from the engineering record.
- The app uses a monochrome π + flexed-arm icon with light and dark backgrounds.
- Smart approvals use labeled destructive-command rules.
- The documentation explains manual deployment to Cloudflare Pages and Netlify.
- The unused `netlify.toml` is removed. Netlify uses manual upload or dashboard settings.
- No application behavior changes from the 0.0.3 source.

The 0.0.3 GitHub release is a draft. It is not published and does not serve updates.
macOS builds are ad-hoc signed. Windows builds are unsigned. The Linux archive includes `install.sh`.

Full Changelog: https://github.com/ModyQyW/pis/compare/v0.0.2...v0.0.4
