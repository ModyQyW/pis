# Keyboard shortcuts

PiS uses native menus. On Windows and Linux, `⌘` means `Ctrl`.

## Global

| Action | macOS | Windows / Linux |
|---|---|---|
| Command palette | `⌘K` | `Ctrl+K` |
| New session | `⌘N` | `Ctrl+N` |
| Open project | `⌘O` | `Ctrl+O` |
| Close session | `⌘W` | `Ctrl+W` |
| Settings | `⌘,` | `Ctrl+,` |
| Show or hide the sidebar | `⌘B` | `Ctrl+B` |
| Show or hide the changes panel | `⌘⇧G` | `Ctrl+Shift+G` |
| Session tree | `⌘⇧T` | `Ctrl+Shift+T` |
| Compact context | `⌘⇧C` | `Ctrl+Shift+C` |
| Model and thinking | `⌘⇧M` | `Ctrl+Shift+M` |
| Stop the current run | `Esc` | `Esc` |

`Esc` stops a run only when:

- The current session is running.
- No inline dialog is open.

## Composer

| Action | Key |
|---|---|
| Send | Enter |
| New line | Shift+Enter |
| Change the send key | Send on Enter in Settings |
| Send when Send on Enter is off | `⌘Enter` / `Ctrl+Enter` |
| Insert a file reference | `@` |
| Open pi commands | `/` |
| Move through suggestions | `↑` / `↓` |
| Insert a suggestion | Enter or Tab |
| Close suggestions | Esc |

While pi runs, Enter adds the message to the current run. The composer hint shows "Enter queues".

## Command palette

| Action | Key |
|---|---|
| Next item | `↓` |
| Previous item | `↑` |
| Run | Enter |
| Close | Esc |

## Inline dialogs

| Action | Key |
|---|---|
| Send text | `⌘Enter` / `Ctrl+Enter` |
| Cancel | Click the close button at the top right |

## Menus

Menu actions match the shortcuts. Some actions have no shortcut:

- Rename session.
- Export HTML.
- Reveal session file.
- Check for updates.
- Open pi documentation.
- Open mygo documentation.

Menu text stays in English. The interface language does not change it.
