# 项目

项目是 PiS 的工作目录。一个项目通常是一个 Git 仓库，也可以是一个普通文件夹。

## 打开项目

有三种方式：

1. 点击侧边栏的「打开项目文件夹」。
2. 按 `⌘O`（Windows/Linux 为 `Ctrl+O`）。
3. 在菜单里选择「文件 > 打开项目…」。

选择目录后，PiS 会把它加入项目列表，并设为当前项目。

项目名称取目录名。PiS 不修改项目文件，也不创建自己的数据库。

## 切换项目

点击侧边栏中的项目，可以切换当前项目。

切换项目后：

- 顶栏显示新项目名称。
- 对话列表显示新项目的会话。
- 输入框继续使用新项目作为工作目录。

已经打开的会话不会关闭。每个会话有自己的 pi 进程和工作目录。

## 最近项目

侧边栏按最近打开时间列出项目。PiS 最多保留 20 个最近项目。

下次启动时，PiS 会恢复上次使用的项目和上次打开的会话。

如果上次的项目已经移动或删除，打开会话时可能失败。请重新打开项目目录。

## 项目信任

第一次打开包含项目级 pi 资源的项目时，PiS 会显示信任对话框。

项目级资源包括：

- `.pi/settings.json`
- `.pi/mcp.json`
- `.pi/extensions`
- `.pi/skills`
- `.pi/prompts`
- `.pi/themes`
- `.pi/SYSTEM.md`
- `.pi/APPEND_SYSTEM.md`
- 项目根目录或上级目录中的 `.agents/skills`

选择「信任项目」后，pi 会加载这些资源。选择「不信任」后，pi 会跳过它们。

信任决定按项目保存。已有会话保持启动时的信任状态。要改变信任范围，请关闭会话，再打开新会话。

信任对话框的完整说明见[信任、审批与计划模式](/guide/approvals)。

## 工作树

Git 工作树可以让同一个仓库有多个并行检出的目录。

PiS 可以列出、创建、打开和移除工作树。工作树目录可以作为普通项目打开。

详细用法见[工作树](/guide/worktrees)。

## 项目文件

PiS 只读取项目文件。它不会替换项目中的文件，也不会为项目创建隐藏目录。

pi 可以在项目里执行命令和修改文件。具体行为取决于你允许的工具和审批策略。
