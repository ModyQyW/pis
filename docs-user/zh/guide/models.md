# 模型与登录

PiS 使用 pi 的模型和凭据。它不保留自己的一份副本。

## 查看 pi 配置

PiS 在启动时读取 pi 的配置。配置与上次确认时不同，PiS 会打开「pi 配置」对话框。对话框列出：

- `settings.json` 中的默认提供商、模型和思考级别。
- `models.json` 中的自定义提供商和模型。
- 技能、扩展和包。
- `mcp.json` 中的 MCP 服务器。

点击「使用此配置」记录确认。也可以从「设置 → pi 资源 → 模型、提供商、技能…」打开。

只有你在对话框中保存时，PiS 才写入 pi 的文件。PiS 不写入 pi 的 `auth.json`、`trust.json` 或会话文件。

## 登录提供商

有两条入口：

1. 设置中的「登录提供商…」。
2. 会话区的「连接提供商」提示。

![登录提供商](/images/login.png)

登录步骤：

1. 输入提供商 ID，例如 `anthropic`、`openai`、`google` 或 `openrouter`。
2. 选择登录方式。
3. 点击「开始登录」。
4. 在应用内终端中完成登录。

两种登录方式：

| 方式 | 行为 |
|---|---|
| 账户登录 | 打开提供商的浏览器登录流程 |
| API key | 在终端中询问密钥 |

登录实际运行：

```sh
pi auth login <provider>
```

PiS 只为 pi 提供终端窗口。凭据由 pi 保存。

注意：

- PiS 不记录终端输出。
- 诊断报告不包含凭据。
- 同一时间只能打开一个登录终端。
- 关闭登录窗口时，登录进程会停止。
- 不确定提供商 ID 时，先查 [pi 提供商文档](https://pi.dev/docs/latest/providers)。

登录成功后，PiS 会刷新模型列表。

## 配置默认值和自定义提供商

打开「设置 → pi 资源 → 模型、提供商、技能…」。

默认值：

- 默认提供商和模型：pi 和新会话的启动选择。
- 思考级别：启动级别。「自动」使用 pi 自己的选择。
- 留空会移除设置项，由 pi 自动选择。

模型和提供商：

- 对话框列出 pi `models.json` 中的提供商。
- 「添加提供商」可以新建提供商，填写 Base URL、API 类型、密钥和模型。
- 每个模型有 ID、可选名称、上下文窗口、最大输出和推理标记。
- 模型选择器只切换当前会话。默认值影响新会话。

可用模型名称来自 `pi --list-models`。内置提供商使用 pi 登录；`models.json` 用于兼容端点和模型覆盖。

保存自定义提供商密钥时，密钥写入 pi 的 `models.json`。PiS 不会再次读取它，下次编辑时输入框为空。`$NAME` 表示 pi 启动时读取环境变量。`compat`、`headers`、`cost` 和 `modelOverrides` 等高级字段仍在 `models.json` 中编辑。

pi 接受 `models.json` 中的 `//` 注释和尾随逗号。PiS 可以读取它们。从 PiS 保存后，文件变为纯 JSON，注释会被移除。会发生这种情况时，对话框会显示警告。

## 模型选择器

打开会话后，点击输入框下方的模型名称。

模型选择器显示：

- 当前模型。
- 可用模型列表。
- 每个模型的提供商和上下文窗口。
- 当前模型的思考级别。
- 自动上下文压缩开关。

模型列表来自 pi 的配置和登录状态。点击刷新按钮可以重新读取。

选择模型后，切换只影响当前会话。新会话使用 pi 的默认模型。

## 思考级别

部分模型支持思考级别。

可选级别由 pi 返回，通常包括 `off`、`low`、`medium` 和 `high`。不同模型的范围可能不同。

修改后，后续消息使用新的思考级别。

## 自动上下文压缩

pi 可以在上下文接近上限时自动压缩。

- 开关默认开启。
- 关闭后，上下文达到上限时可能失败。
- 你也可以从菜单选择「压缩上下文…」，手动压缩。

压缩后，会话区显示一条摘要。PiS 保留历史消息的显示，pi 使用摘要继续对话。

## 上下文用量

输入框右下角显示当前上下文占用百分比。

百分比来自 pi 的会话统计。它包含系统提示、工具定义、历史消息和当前回复。

上下文占用较高时，可以：

- 手动压缩上下文。
- 新建会话。
- 切换到上下文窗口更大的模型。

## 没有可用模型

如果登录缺失或模型配置为空，会话区会显示「没有可用模型」。

处理步骤：

1. 点击「连接」或打开设置。
2. 完成提供商登录。
3. 回到会话，点击模型选择器的刷新按钮。

如果仍然没有模型，检查 pi 自己的模型配置和登录状态。具体命令以 [pi 文档](https://pi.dev/docs/latest/models) 为准。

## 凭据安全

- 凭据保存在 pi 的目录中。
- PiS 不读取 pi 的 `auth.json`。
- 你保存的自定义提供商密钥写入 pi 的 `models.json`。PiS 不会再次显示它，也不保存到自己的设置。
- PiS 不把凭据写入日志、诊断或会话文件。
- 不得在项目文件中保存 API key。
- 不得把包含密钥的截图或日志发到公开 issue。
