# 快捷键

PiS 使用原生菜单。Windows 和 Linux 中，`⌘` 对应 `Ctrl`。

## 全局

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 命令面板 | `⌘K` | `Ctrl+K` |
| 新建会话 | `⌘N` | `Ctrl+N` |
| 打开项目 | `⌘O` | `Ctrl+O` |
| 关闭会话 | `⌘W` | `Ctrl+W` |
| 设置 | `⌘,` | `Ctrl+,` |
| 显示/隐藏侧边栏 | `⌘B` | `Ctrl+B` |
| 显示/隐藏更改面板 | `⌘⇧G` | `Ctrl+Shift+G` |
| 会话树 | `⌘⇧T` | `Ctrl+Shift+T` |
| 压缩上下文 | `⌘⇧C` | `Ctrl+Shift+C` |
| 模型与思考 | `⌘⇧M` | `Ctrl+Shift+M` |
| 停止当前运行 | `Esc` | `Esc` |

`Esc` 只在以下情况停止运行：

- 当前会话正在运行。
- 没有打开的内联对话框。

## 输入框

| 操作 | 按键 |
|---|---|
| 发送 | Enter |
| 换行 | Shift+Enter |
| 切换发送键 | 设置中的「按 Enter 发送」 |
| 关闭发送键后发送 | `⌘Enter` / `Ctrl+Enter` |
| 插入文件引用 | `@` |
| 打开 pi 命令 | `/` |
| 选择建议 | `↑` / `↓` |
| 插入建议 | Enter 或 Tab |
| 关闭建议 | Esc |

pi 正在运行时，Enter 会把消息加入当前运行。输入框提示显示「Enter 排队」。

## 命令面板

| 操作 | 按键 |
|---|---|
| 下一项 | `↓` |
| 上一项 | `↑` |
| 执行 | Enter |
| 关闭 | Esc |

## 内联对话框

| 操作 | 按键 |
|---|---|
| 发送文本 | `⌘Enter` / `Ctrl+Enter` |
| 取消 | 点击右上角关闭按钮 |

## 菜单

菜单中的操作与快捷键对应。部分操作没有快捷键：

- 重命名会话。
- 导出 HTML。
- 显示会话文件。
- 检查更新。
- 打开 pi 文档。
- 打开 mygo 文档。

菜单文字保持英文，不受界面语言影响。
