# 日常使用

## 会话

PiS 的会话来自 pi 的 session 文件，不是 PiS 自己的一套数据库。

- 侧边栏按项目列出最近会话。
- 新建、恢复、重命名、克隆、fork、导出 HTML、删除到回收站。
- 会话树可以查看分支并在节点之间切换。
- `⌘K` 打开命令面板，可搜索项目、会话和设置。

关闭窗口不会删除会话；退出应用时如果有运行中的会话，PiS 会先询问是否停止。

## 输入框

- 输入自然语言目标即可，不需要手动选择工具。
- `@` 搜索项目文件。
- 粘贴或拖入图片；图片会作为附件进入本轮消息。
- `/` 浏览 pi 的 slash commands。
- 选择模型和 thinking 级别；可用项来自你的 pi 配置。
- 每个会话独立保存草稿，切换会话不会丢字。

## 工具与变更

工具调用会显示成卡片：shell、read、edit、write、grep、find、ls、todo、子代理，以及扩展注册的通用工具。

右侧面板包含：

- **Changes**：分支状态、逐文件 diff、复制 patch、逐文件还原。
- **Files**：文件树和只读预览。
- **Plan**：当前计划与进度。
- **Agents**：子代理活动。

逐文件还原会修改工作区，确认前看清楚路径和内容。

## 计划模式

输入框旁的 **Plan** 会把会话切到只读探索模式。此时修改类工具会被阻止，模型先给出计划；你确认后再关闭计划模式执行。

计划模式是产品级保护，不是安全沙箱。

## 通知、语言和外观

后台会话结束时可以发系统通知。设置里可以切换：

- 主题：系统 / 浅色 / 深色
- 语言：English / 中文
- TUI widget：默认关闭，因为它们按终端布局设计
- 通知权限和测试通知

## 键盘

| 操作 | 快捷键 |
|---|---|
| 命令面板 | `⌘K` / `Ctrl+K` |
| 新建会话 | `⌘N` |
| 切换侧边栏 | `⌘B` |
| 切换变更面板 | `⌘⇧G` |
| 会话树 | `⌘⇧T` |
| 发送 | Enter |
| 换行 | Shift+Enter |

菜单和快捷键在 macOS 使用原生菜单；Windows/Linux 使用对应窗口菜单。
